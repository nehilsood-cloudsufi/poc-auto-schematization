2. Retry Loop — Sequence Diagram

sequence 
sequenceDiagram
    participant SP as StatePrep
    participant SV as StatVarDiscovery
(MCP only)
    participant GEN as PVMAPGenerator
(LlmAgent)
    participant META as MetadataGen
    participant VAL as Validation
    participant QE as QualityEval
    participant MR as MaxRetries
    participant FB as Feedback
(LlmAgent)

    rect rgb(30, 40, 60)
        Note over SP,FB: Attempt 0 — Initial Generation
        SP->>SP: attempt=0, init tracking
populate prompt template
        SP->>SV:
        SV->>SV: MCP StatVar search (if enabled)
        SV->>GEN: statvar_summary
        GEN->>GEN: Generate PVMAP
output_schema=PVMAPOutput
Schema.org + DC tools
        GEN->>META: pvmap_output (JSON)
        META->>META: Generate output_metadata.csv
        META->>VAL:
        VAL->>VAL: JSON→CSV, repair keys
pre-validate, subprocess
key_match_report

        alt Validation PASSED
            VAL->>QE: validation_passed=True
            QE->>QE: Heuristic score + GT accuracy
            alt Quality Acceptable
                QE-->>QE: ESCALATE (exit loop)
                Note over QE: exit: quality_met
            else Stagnant
                QE-->>QE: ESCALATE (exit loop)
                Note over QE: exit: stagnant
            else Low but Improving
                QE->>MR: Continue
                MR->>FB: Not at max
                FB->>FB: Quality feedback
compact + escape
                FB-->>SP: error_feedback
            end
        else Validation FAILED
            VAL->>QE: validation_passed=False
            QE->>MR: Skip quality, continue
            MR->>FB: Not at max
            FB->>FB: Error feedback
validation_error + key_match
            FB-->>SP: error_feedback
        end
    end

    rect rgb(40, 30, 30)
        Note over SP,FB: Attempt 1..N — Retry with Feedback
        SP->>SP: attempt++, inject feedback
        SP->>GEN: prompt with error_feedback
        Note over GEN: Improved PVMAP generation
        GEN->>VAL: same validation flow
    end

    rect rgb(50, 20, 20)
        Note over MR: Max Retries Exceeded
        MR->>MR: Restore best attempt
Re-validate, ESCALATE
        Note over MR: exit: max_retries
    end
