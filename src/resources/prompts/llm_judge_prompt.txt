## EVALUATION RUBRIC

Score each dimension from 1 to 5 using these anchors:

### 1. Structural Quality
Evaluates completeness and pattern recognition.
- Are ALL data columns from the input mapped in the PVMAP?
- Are the required triples present: observationAbout (place), observationDate (time), value (measurement)?
- Is the correct data archetype identified (wide/pivoted, flat/tidy-long, dimension-row, census-coded)?
- Is the row count appropriate for the data structure?

Score anchors:
- 1: Missing required triples (no observationAbout or observationDate mapping)
- 2: Required triples present but many columns unmapped
- 3: All triples present, some columns unmapped
- 4: Nearly complete, minor structural gaps
- 5: Complete and correct structure, all columns properly mapped

### 2. Semantic Accuracy
Evaluates whether the right Data Commons properties are used.
- Are the correct DC properties chosen (e.g., age vs ageGroup, gender vs sex)?
- Do properties match the expected schema category vocabulary?
- Are DCIDs well-formed and plausible (dcid:schema/PropertyName format)?
- Are properties properly decomposed instead of using variableMeasured shortcuts?

Score anchors:
- 1: Wrong property types throughout, fundamental misunderstanding of DC schema
- 2: Some correct properties but many wrong choices
- 3: Mostly correct with a few wrong property selections
- 4: Nearly all properties correct, minor naming issues
- 5: All properties correctly chosen and properly decomposed

### 3. Value Mapping Quality
Evaluates placeholder usage, column references, and value correctness.
- Are {{Data}} and {{Number}} placeholders used correctly ({{Data}} for text, {{Number}} for numeric)?
- Are column references exact (case-sensitive match to actual column headers)?
- Are enum values valid for their properties?
- Are units, scaling factors (#Multiply), and aggregations (#Aggregate) handled?

Score anchors:
- 1: Broken placeholders, wrong column references, invalid values
- 2: Some correct but many mapping errors
- 3: Mostly correct with minor placeholder or reference issues
- 4: Nearly perfect, one or two small value issues
- 5: All values correctly mapped, exact column references, valid enums
